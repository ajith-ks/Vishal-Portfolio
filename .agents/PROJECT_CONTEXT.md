## 7. ShinyButton Implementation Details

- **Generator**: `renderShinyButton({ text, href, id, icon, onClick })` in `src/main.js:62`.
- **Markup**: Outputs an `<a class="shiny-btn">` if `href` is supplied, or `<button type="submit" class="shiny-btn">` if `href` is absent.
- **Visual Mechanics**:
  - `::after` pseudo-element provides an animated rotating gradient border via `shinyBorderRotate` (6s cycle).
  - `::before` pseudo-element provides a periodic diagonal shimmer sweep via `shinySweep` (4.5s cycle).
  - `.shiny-btn-content` inner span isolates text and icons with `z-index: 2`.
  - Supports loading spinner (`.btn-spinner`) for asynchronous states.

## 8. 3D Scene Architecture & Reduced-Motion Handling

- **Class**: `ThreeSculpture` in `src/components/ThreeSculpture.js`.
- **Canvas Mount**: Injected into `<div id="hero-3d-stage"></div>`.
- **Objects**:
  - 3 nested orbital rings with standard metallic materials (`MeshStandardMaterial`).
  - Core icosahedron geometry with dual-color wireframe and vertex shading.
  - 140 ambient particle points orbiting the sculpture.
- **Responsive Scaling**: Dynamic scale adjustments based on screen width (`0.72` on mobile <=768px, `0.85` on tablet <=1024px, `1.0` on desktop).
- **Theme Adaptation**: `updateTheme(theme)` updates lighting hues and material colors when the user switches between dark and light themes.
- **Accessibility (`prefers-reduced-motion`)**:
  - Checks `window.matchMedia('(prefers-reduced-motion: reduce)').matches`.
  - If enabled, rotation animations are halted; a static composition is rendered.
  - Lenis smooth scroll and custom cursor animations are likewise disabled in `src/motion/motionEngine.js`.

## 10. Contact Form & Email Integration Status

- **Form DOM**: `<form id="contact-form">` with inputs `#c-name`, `#c-email`, `#c-subject`, `#c-message`.
- **Handler**: `setupContactForm()` in `src/main.js:1191`.
- **Validation**: Client-side check for name, valid email regex (`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`), subject, and message length (>= 10 chars).
- **Transmission Mechanism**: **Client-side `mailto:` protocol**.
  - Recipient: `k.vishalnair@gmail.com`.
  - Creates a dynamic `<a>` element with `href="mailto:..."`, `target="_blank"`, and triggers `mailLink.click()`.
  - Renders a helper alert box (`#form-status-alert`) with a "Copy Email Address" button.
- **Integration Status**: **NO server-side endpoint or email service API (e.g. Formspree, EmailJS, Resend) is configured.**
- **Why "Send Enquiry" Fails / Known Root Causes**:
  1. *No default mail application*: In browsers or operating systems with no configured desktop email client (such as Outlook or Apple Mail), clicking `mailto:` fails silently or does nothing.
  2. *Popup blocking / blank tabs*: Appending `target="_blank"` to a `mailto:` link causes modern browsers to either block the action as a popup or open a blank `about:blank` window.
  3. *User expectation mismatch*: Visitors expect immediate in-page confirmation rather than an external mail client launch.
