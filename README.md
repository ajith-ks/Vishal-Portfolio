# Dr. Vishal Kattery — Premium Animated Portfolio

A bespoke, production-quality personal portfolio website crafted for **Dr. Vishal Kattery** — Professor, Mentor, Placement Trainer, Counselor, and Banker based in Palakkad, Kerala, India.

---

## 1. Project Overview

The website communicates Dr. Vishal's multidimensional career across:
- **Academic Rigor**: Ph.D. in Management, M.Com (CA), MBA, HDCM, Dip. in Finance, BCA.
- **Teaching & Student Impact**: Over 100 motivational and career-oriented sessions across schools and colleges in South India.
- **Research Excellence**: SCOPUS-indexed publications examining private banking employee stress and commitment.
- **Industry Exposure**: Direct leadership and operational roles across software development (TCS), cooperative banking, and corporate directorship (Telious Technologies).
- **Civic Governance**: Frontline disaster management volunteer (Civil Defence – Kerala Fire Rescue Services NDMA/KSDMA, Covid-19 Rapid Response Team, Kerala Emergency Team).

---

## 2. Design & Architecture Highlights

- **Design Aesthetic**: Editorial Academic × Human × Cinematic. Deep obsidian/graphite dark mode default, with a warm alabaster light mode.
- **Color System**: Curated palette with warm Champagne Gold (`#D8B260`) as the primary accent, paired with high-contrast, accessible typography.
- **Motion & Smooth Scroll**: Centralized `requestAnimationFrame` ticker powering Lenis smooth scrolling, desktop magnetic cursor follower, scroll-linked progress rails, and text-reveals.
- **Accessibility & Responsiveness**: Mobile-first responsive grid layouts, WCAG-compliant contrast ratios, and complete graceful degradation under `prefers-reduced-motion`.
- **Zero Third-Party Video Embeds**: Dedicated self-hosted HTML5 video player for authentic classroom training documentation.
- **Strict Social Platform Governance**: Direct verified links to LinkedIn, Instagram, and Facebook only.

## 4. Testimonial Excel System

The testimonial system is fully decoupled and data-driven:
1. Open `content/testimonials/testimonials.xlsx`.
2. Add records to the **`Testimonials`** worksheet:
   - **Name** (Required)
   - **Student / Faculty** (Optional, dropdown validation)
   - **Institution Name** (Optional)
   - **Testimony** (Required)
3. Save the file and run:
   ```bash
   npm run build
   ```
   *(Or `node scripts/convert-testimonials.js` during development).*
4. The interactive testimonial slider will automatically update and render the new testimonials. When blank (0 records), the website displays a clean, development-ready state without broken counters or placeholder names.

## 5. Development & Build Commands

- **Install Dependencies**:
  ```bash
  npm install
  ```
- **Run Local Development Server**:
  ```bash
  npm run dev
  ```
  *(Starts the dev server at `http://localhost:3000`)*
- **Build for Production**:
  ```bash
  npm run build
  ```
  *(Converts testimonials, optimizes bundles, and packages assets into `dist/`)*
- **Preview Production Build**:
  ```bash
  npm run preview
  ```
